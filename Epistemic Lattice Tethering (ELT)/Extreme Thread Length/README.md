# Extreme Thread Length — Working Threads

This folder contains redacted transcripts of extended ELT-governed threads
across three frontier models: a 450k token Claude thread, a 1.15 million
token Grok thread, and a 450k token GPT thread.

**These are not demonstrations.**

They are production working threads — the actual development environment in
which ELT was built, tested, and iterated. They contain failures, dead ends,
sycophancy spirals, recycling, and off-rails exchanges alongside the useful 
work. That is the point. Every significant component of ELT can be traced 
back to a failure mode that first appeared in one of these threads.

Reading them as demos would be the wrong frame. Reading them as lab
notebooks — messy, iterative, and honest about what didn't work — is the
right frame.

They are included here for two reasons: as evidence that extreme thread
lengths are achievable with ELT scaffolding, and as primary source material
for researchers or developers who want to understand how the framework
evolved from observed failure to documented practice.

These results are operator-reported from a single extended testing program
and have not been independently replicated. They are evidence worth taking
seriously, not proof.
